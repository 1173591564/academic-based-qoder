## 触发
当用户说"帮我入门 XX 方向"、"从零开始研究 XX"、"新方向调研"、"我不了解 XX 领域"时执行此流程。

## 流程

### Step 1: 评估本地知识库
```bash
python -m scholar search "<目标方向>"
python -m scholar rag-search "<目标方向>" --hybrid
```
检查本地库中有多少相关论文：
- **>20 篇**：本地库足以支撑冷启动，进入 Step 2a
- **5-20 篇**：本地库有部分覆盖，进入 Step 2b
- **<5 篇**：本地库覆盖不足，进入 Step 2c

检查概念图谱覆盖率：
```bash
python -m scholar graph-query <目标概念>
```
如果概念图谱中已有该方向的 Innovation 节点，可以直接利用 REPLACES 关系作为演化证据。

### Step 2a: 基于本地库冷启动
```bash
python -m scholar list-papers
```
从搜索结果中选取被引最多的 5 篇论文，执行深度阅读。

### Step 2b: 混合冷启动
先利用本地库论文建立基础认知，再用 arXiv 补充。

### Step 2c: 基于 arXiv 冷启动
```bash
python -m scholar arxiv-search "<目标方向>" --max 30
python -m scholar arxiv-search "<相关子方向>" --max 20
```
从 arXiv 结果中筛选：
- 高引用/高影响力的综述论文（survey）优先
- 近 2 年的最新工作
- 经典开创性工作

### Step 3: 构建知识地图
基于 Step 2 收集的论文，构建概念知识地图：
1. 识别核心概念和术语
2. 概念之间的依赖关系（A 是 B 的基础）
3. 概念的分类层次
4. 关键人物和研究组

### Step 4: 时间线梳理
按年份排列关键事件：
- 方向何时出现？
- 哪些论文是里程碑？
- 当前处于什么阶段？（初期探索 / 快速发展 / 成熟稳定）

### Step 5: 核心论文精读
选取 3-5 篇最重要的论文，先检查预生成笔记：
- `output/notes/<ULID>.md` — 已提取的摘要、贡献、公式
- `output/notes/<ULID>-quality.json` — 7维度质量评分
如果笔记已存在，直接基于笔记分析；否则执行 paper-deep-dive 流程：
- 如果是综述论文，重点关注分类体系和研究脉络
- 如果是开创性论文，重点关注问题定义和核心方法
- 如果是最新论文，重点关注当前前沿和开放问题

### Step 6: 与已有知识关联
检查新概念与用户已熟悉的概念之间的关联：
```bash
python -m scholar search "<用户已知的概念>"
```
找到连接点，帮助用户从已知概念桥接到新概念。

### Step 7: 概念图谱辅助（如可用）
```bash
python -m scholar graph-query <概念>
python -m scholar graph-stats
```
查看新概念在已有概念图谱中的位置和关联：
- HAS_CONCEPT 边：哪些论文与这个概念相关
- RELATED_TO 边：哪些概念经常共现
- REPLACES 边：技术演化关系（新方法替代旧方法）

### Step 8: 输出冷启动指南
输出到 `output/drafts/cold-start-<topic>.md`：

```markdown
## 冷启动指南: <topic>

### 一句话定义
<用最通俗的语言解释这个方向是什么>

### 为什么重要
<2-3 句话说明这个方向的研究价值>

### 核心概念 (N个)
1. **<概念1>**: <定义> — 代表论文: <paper_id>
2. **<概念2>**: <定义> — 代表论文: <paper_id>
...

### 必读论文 (按顺序)
1. <综述论文> — 先读这篇建立全局认知
2. <开创性论文> — 理解问题起源
3. <最新工作> — 了解当前前沿
4. ...

### 发展时间线
| 年份 | 里程碑 | 论文 |
|------|--------|------|
| ...  | ...    | ...  |

### 关键研究组
| 研究组 | 机构 | 代表工作 |
|--------|------|---------|
| ...    | ...  | ...     |

### 与已有知识的连接
- <用户熟悉的概念A> 与 <新概念X> 的关系: ...
- ...

### 建议学习路径
1. <第一步做什么>
2. <第二步做什么>
...

### 推荐进一步阅读
- 参考 research-survey 流程进行深度调研
- 参考 paper-recommendation 流程获取个性化推荐
```

## 注意事项
- 冷启动指南要面向初学者，避免术语堆砌
- 每个概念首次出现时都要解释
- 必读论文列表要给出阅读顺序（先读综述再读经典再读前沿）
- 如果本地库覆盖不足，明确建议用户下载哪些论文

## Next Steps

冷启动完成后，自然的后续动作：

- **`/research-survey`** — 对知识地图中的核心方向做深入调研
- **`/paper-deep-dive`** — 按学习路径精读必读论文
- **`/citation-network`** — 分析该领域的引用网络，发现经典论文

> 传递数据：知识地图中的「必读论文列表」和「概念依赖图」可直接指导后续阅读顺序。
