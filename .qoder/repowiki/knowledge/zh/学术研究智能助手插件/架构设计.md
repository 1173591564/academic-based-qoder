- **入口与元数据**：`.qoder-plugin/plugin.json` 定义插件名称、版本及资源路径（skills, commands, rules, hooks, mcpServers）。
- **能力层 (Skills)**：`skills/` 目录下包含18个原子技能和4个组合工作流（如 `research-survey`, `writing-pipeline`），每个技能通过 `SKILL.md` 定义触发条件、执行步骤及数据依赖。
- **交互层 (Commands & Rules)**：`commands/` 提供快捷指令（如 `stats`, `find`），`rules/identity.md` 确立 Agent 角色边界与“数据驱动”原则。
- **集成层 (MCP & Hooks)**：`mcp.json` 配置 Scholar MCP Server 连接后端 Python 服务；`hooks/hooks.json` 注册任务完成通知与危险命令拦截钩子。
- **依赖方向**：插件作为前端逻辑层，通过 CLI 调用和 MCP 协议依赖外部 `academic-based-qoder` 后端（PostgreSQL/Neo4j/Python）。
