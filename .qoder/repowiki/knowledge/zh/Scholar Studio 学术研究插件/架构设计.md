- **配置驱动架构**：以 `.qoder-plugin/plugin.json` 为核心清单，声明式注册 `skills`、`commands`、`rules`、`hooks` 及 `mcpServers` 路径。
- **能力分层**：`skills/` 目录包含 14 个原子与工作流技能（如 `research-survey`），定义具体执行步骤；`commands/` 提供快捷指令（如 `stats`）；`rules/` 通过 `identity.md` 和 `pipelines.md` 定义 Agent 的心智模型与意图路由逻辑。
- **外部执行代理**：插件本身不包含业务逻辑代码，而是通过 `mcp.json` 配置 Scholar MCP Server（Python 后端），并借助 `hooks/` 中的 PowerShell 脚本实现任务完成通知与危险命令拦截，形成“插件定义规范 + 后端执行计算”的解耦设计。
