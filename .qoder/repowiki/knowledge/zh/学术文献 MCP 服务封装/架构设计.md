- **入口与生命周期**：通过 `__main__.py` 调用 `server.py` 中的 `main()` 启动 MCP 服务。
- **核心架构**：基于 `mcp.server.fastmcp.FastMCP` 框架构建，定义了名为 "Scholar Studio" 的 MCP 实例。
- **适配层模式**：所有 MCP 工具函数（如 `scholar_scan`, `scholar_graph_build`）均作为薄适配层，内部统一调用 `_run_scholar` 辅助函数。
- **执行机制**：`_run_scholar` 通过 `subprocess.run` 以子进程方式执行 `python -m scholar` 命令，实现了 MCP 服务与底层业务逻辑（scholar 模块）的解耦。
- **文件交互**：部分只读工具（如 `read_parsed_paper`）直接通过 `pathlib.Path` 读取项目输出目录下的 JSON 或 Markdown 文件，避免重复调用 CLI。
