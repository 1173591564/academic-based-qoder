- **入口层**：基于 `typer` 构建 CLI (`cli.py`)，通过 `id_resolver.py` 实现 ULID/arXiv/DOI 混合 ID 解析。
- **解析与处理层**：`tex_parser.py` 负责 LaTeX 源码的结构化提取；`year_fix.py`、`metadata_enrich.py` 和 `cite_resolve.py` 利用 arXiv API 进行元数据补全与引用消歧。
- **存储适配层**：采用双数据库架构，`db.py` 封装 PostgreSQL (pgvector) 用于结构化数据与向量索引，`graph_db.py` 封装 Neo4j 用于构建论文引用网络与创新概念图谱。
- **应用增强层**：`rag.py` 实现基于智谱/OpenAI 的语义检索；`auto_notes.py`、`quality.py` 和 `classify.py` 提供自动化笔记生成、质量评分及多维度标签分类。
- **工作流编排**：`kb_update.py` 作为核心编排模块，串联下载、解析、入库、图谱更新及索引构建的全流程。
