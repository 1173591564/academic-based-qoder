- 采用混合架构：Lean4 子模块负责 AI 演进的形式化定理证明与 PDSS 架构建模，Python 子模块（scholar_app）负责文献解析、知识图谱构建及 RAG 检索。
- 数据层共享：两者共用 `infra/` 定义的 PostgreSQL 和 Neo4j 基础设施，Python 模块通过 `scholar/db.py` 和 `scholar/graph_db.py` 进行读写，Lean 模块通过 `AiEvolution/Database.lean` 进行理论映射或数据导出。
- 交互边界：`scholar_mcp` 作为 IDE 集成层，暴露 Python 模块的研究工具接口；Lean 模块的输出（如定理验证结果）可能作为元数据被 Python 模块索引，形成“理论验证-实践应用”的闭环。
- 启动与编排：根目录通过 `pyproject.toml` 管理 Python 依赖与入口，`lakefile.toml` 管理 Lean 构建，两者在物理上隔离但在逻辑上通过共享的数据目录（`data/papers`）和数据库实例协同工作。
