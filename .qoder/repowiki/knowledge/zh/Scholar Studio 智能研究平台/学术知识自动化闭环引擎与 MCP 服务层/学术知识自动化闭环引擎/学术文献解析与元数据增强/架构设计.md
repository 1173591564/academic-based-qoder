- **核心解析层**：`tex_parser.py` 实现基于正则的 TeX 源码深度解析，支持宏展开、嵌套括号处理及多格式作者/标题清洗。
- **身份解析层**：`id_resolver.py` 提供混合 ID（ULID/arXiv/DOI）到内部 ULID 的归一化映射，采用懒加载内存索引优化查询性能。
- **元数据补全层**：`year_fix.py` 和 `metadata_enrich.py` 分别通过 Lean4 数据库交叉引用和 arXiv API 检索，回填缺失的年份、DOI 及作者信息。
- **引用消歧层**：`cite_resolve.py` 利用 Levenshtein 距离进行模糊匹配，将原始引用键解析为内部论文节点或创建外部论文占位符。
- **依赖方向**：各功能模块相对独立，均依赖 `config.py` 获取路径配置，并通过 `_shared.py` 或命令层接口被上层 CLI/MCP 服务调用。
