- **模块化功能分层**：模块由三个独立的功能单元组成，分别负责分类（`classify.py`）、质量评估（`quality.py`）和笔记生成（`auto_notes.py`），均通过 `from . import config` 共享全局配置。
- **规则驱动的分类体系**：`classify.py` 内置了包含 NLP、CV、RL 等领域的层级化关键词词典（`DOMAINS`）及会议提示（`VENUE_HINTS`），通过文本匹配与计分机制实现多级标签提取。
- **多维质量评分模型**：`quality.py` 定义了七个独立的评分维度（如元数据完整性、结构质量、可复现性等），每个维度由私有函数（如 `_score_metadata`）实现，最终聚合为总分与等级（A-F）。
- **模板化笔记生成**：`auto_notes.py` 采用启发式正则表达式从论文摘要和章节中提取核心贡献与方法概述，并结合公式权重算法筛选关键公式，输出标准化的 Markdown 阅读笔记。
- **批处理与单点处理接口**：每个单元均提供针对单个 ULID 的处理函数（如 `classify_single_paper`）以及遍历 `PARSED_DIR` 的批量处理函数，实现逻辑复用。
