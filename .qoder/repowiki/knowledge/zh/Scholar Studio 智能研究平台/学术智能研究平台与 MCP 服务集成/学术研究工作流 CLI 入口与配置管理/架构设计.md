- **入口层**：`__main__.py` 作为 Python 模块执行入口，调用 `cli.py` 中的 `main()` 函数启动应用。
- **共享层**：`_shared.py` 集中定义 Typer 应用实例、Rich 控制台、TeX 解析器及数据库连接助手，作为单一事实来源供入口和命令模块引用，彻底消除循环导入。
- **命令注册**：`cli.py` 通过动态导入 `commands/` 目录下的功能子模块（如 `paper_ops`, `graph_ops`）自动注册 CLI 命令。
- **配置层**：`config.py` 实现开发模式与 PyInstaller 打包模式的双模适配，根据 `sys.frozen` 状态动态解析 `SCHOLAR_HOME` 和 `WORKSPACE_DIR`，并负责初始化目录结构与加载 `.env` 环境变量。
