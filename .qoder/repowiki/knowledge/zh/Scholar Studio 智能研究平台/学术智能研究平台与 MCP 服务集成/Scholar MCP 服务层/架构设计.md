- **入口与生命周期**：通过 `__main__.py` 调用 `server.py` 中的 `main()` 启动 MCP 服务器，采用 `python -m scholar_mcp` 方式运行。
- **核心框架**：依赖 `mcp.server.fastmcp.FastMCP` 构建服务端，定义全局实例 `mcp` 并注册大量 `@mcp.tool()` 装饰的函数。
- **执行代理模式**：绝大多数工具函数（如 `scholar_parse`, `scholar_graph_build`）不直接实现业务逻辑，而是通过 `_run_scholar` 辅助函数以子进程方式调用宿主项目的 `scholar` CLI 模块 (`subprocess.run`)，实现服务层与业务逻辑层的解耦。
- **文件直读层**：针对笔记、质量评分、解析结果等静态产物，提供 `read_*` 系列工具，直接通过 `pathlib` 读取 `output/` 目录下的 JSON 或 Markdown 文件，避免重复调用 CLI。
- **路径上下文**：动态计算 `PROJECT_ROOT` 以确保子进程调用和文件读取均基于正确的项目根目录。
