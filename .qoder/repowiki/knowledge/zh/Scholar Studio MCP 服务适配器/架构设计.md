- **入口与初始化**：`__main__.py` 作为模块入口调用 `server.main()`，`server.py` 初始化 `FastMCP` 实例并定义全局 `PROJECT_ROOT`。
- **核心适配层**：通过 `_run_scholar` 函数利用 `subprocess` 统一调度外部 `scholar` 模块命令，实现 CLI 到 MCP 工具的透明转换。
- **功能分组**：工具按领域划分为文献库管理（Paper Library）、图网络（Graph & Network）、RAG 检索、元数据补全、工作流编排（Orchestration）、知识库更新（KB Update）及执行层（Execution Layer）。
- **文件直读机制**：针对笔记、质量评分及解析后的 JSON 数据，采用直接读取 `output/` 目录下文件的策略，并集成 `scholar.id_resolver` 进行 ID 标准化处理。
