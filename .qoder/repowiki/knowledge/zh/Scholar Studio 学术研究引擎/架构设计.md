- **分层架构**：采用 CLI (`scholar/`) 与 MCP Server (`scholar_mcp/`) 分离的设计，通过 `_shared.py` 共享 Typer 应用实例与数据库连接。
- **模块化命令系统**：CLI 命令按功能拆分为 `commands/` 下的多个模块（如 `core_ops`, `graph_ops`, `rag_ops`），实现逻辑解耦。
- **数据层集成**：底层依赖 PostgreSQL (pgvector) 进行结构化存储与向量检索，Neo4j 处理概念与引用图谱，并通过 `config.py` 统一管理多环境配置。
- **形式化验证扩展**：集成 Lean4 项目 (`LEAN/`)，通过 `lakefile.toml` 管理定理证明与学术创新的形式化验证。
