- **分层架构**：`scholar` (核心逻辑/CLI) -> `scholar_mcp` (MCP 适配器) -> `qoder_plugin` (IDE 交互层)，通过 FastMCP 协议解耦。
- **混合存储底座**：`infra` 模块提供 PostgreSQL (pgvector) 与 Neo4j 的统一容器化环境，支撑结构化元数据、向量检索及概念图谱。
- **形式化验证集成**：`LEAN` 项目作为独立的形式化引擎，通过 CLI 技能被调度，用于 AI 演进定理的数学正确性校验。
- **统一工作流驱动**：插件层定义的 14 个 Skills 映射到底层 CLI 命令，实现从自然语言指令到复杂学术任务的自动化执行。
